# DesignSystem

Design tokens and shared components for Waymark (spec 6.1). SwiftUI, no other
dependencies.

| File | Contents |
|---|---|
| `Theme.swift` | `Spacing` / `Radius` scales, `Color.brand`, `Font.placeHeadline` / `.placeTitle` |
| `Components.swift` | `Card`, `PrimaryButton`, `MetricBadge`, `EmptyStateView` |

Kept intentionally small — the app screens compose these plus stock SwiftUI. Extends as
F7 (share image) and F8 (settings polish) need it.
